# Music Collection Catalog

A lightweight Python application for managing a unified music collection from multiple sources.

## Overview

Music Collection Catalog combines albums listened to on a smartphone, desktop computer, and vinyl records into a single catalog.

The project demonstrates object-oriented programming, modular architecture, data aggregation, and simple statistics.

## Features

- Combine collections from multiple sources
- View complete music library
- Count albums by source
- Artist statistics
- Average album rating
- Collection summary

## Sources

- Smartphone
- Desktop Computer
- Vinyl Collection
